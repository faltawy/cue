# Release notes

`desktop/<version>.md` is generated by `pnpm release:version` from the pending changesets in `.changeset/`; do not hand-write it. The app shows the file for its own version in What's new, and the release workflow publishes it as the public release notes.

Notes are user-facing outcomes only: no commit hashes, links, issue numbers, contributor names, internal changes, or model and vendor names. See `.changeset/README.md` and `docs/RELEASING.md`.
