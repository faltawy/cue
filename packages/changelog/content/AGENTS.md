# Release notes

`desktop/<version>.md` is generated by `pnpm release:version` from the pending changesets in `.changeset/`; do not hand-write it. The app bundles every versioned file for its What's new history, opens on the installed version, and lets people choose earlier releases. The release workflow publishes the current version as the public release notes.

Notes are user-facing outcomes only: no commit hashes, links, issue numbers, contributor names, internal changes, or model and vendor names. See `.changeset/README.md` and `docs/RELEASING.md`.
