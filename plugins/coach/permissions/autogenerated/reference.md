## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-complete-dictation`
- `allow-llm-endpoint`
- `allow-assistant-endpoint`
- `allow-show-assistant`
- `allow-get-settings`
- `allow-set-settings`
- `allow-choose-project`
- `allow-probe-mcp-server`
- `allow-set-mcp-secret`
- `allow-mcp-statuses`
- `allow-find-claude-connectors`
- `allow-add-knowledge`
- `allow-show`
- `allow-show-for-recording`
- `allow-claude-signed-in`
- `allow-sign-in-to-claude`
- `allow-claude-code-status`
- `allow-update-claude-code`
- `allow-claude-setup`
- `allow-retry-claude-setup`
- `allow-provider-account`
- `allow-sign-in-to-provider`
- `allow-provider-setup`
- `allow-retry-provider-setup`
