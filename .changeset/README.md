# Changesets

Every user-visible change to Cue ships with a changeset: run `pnpm changeset`, pick `@anlg/desktop`, choose `patch` (fixes) or `minor` (new features), and write one or two plain sentences about what users notice, not how it was built. No commit hashes, links, issue numbers, names, or model and vendor names. These sentences become the public release notes and the in-app What's new, so keep them outcome-only. See `docs/RELEASING.md` for cutting a release.
