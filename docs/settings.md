# Settings reference

This page lists every setting in Cue, page by page, and links to the guide that explains it. Open Settings with ⌘,, from the menu bar icon, or with ⌘K. The search box at the top of the settings list finds a page by name.

## App

### General

| Setting | What it does |
| ------- | ------------ |
| Your name | Your name in transcripts. The coach listens for it. |
| Start Cue at login | Opens Cue when you log in. Off at first. |
| Show app in Dock | On at first. |
| Show tray icon | Shows the menu bar icon. On at first. See [Menu bar and Dock](setup.md#menu-bar-and-dock). |
| Coach shortcut | ⇧⌘K at first. See [Change the coach shortcut](coach.md#change-the-coach-shortcut). |
| Main language | The usual language for transcription and AI answers. |
| Use main language for summaries | When off, summaries use the meeting's language. |
| Additional spoken languages | Other languages your meetings use. |
| Timezone | The time zone for the note list and calendar. It follows your Mac at first. |
| Week starts on | Sunday or Monday. |
| Export location | Where **Export** saves files. Downloads at first. **Reset to Downloads** sets it back. |
| Updates | Your version, **Check for updates** and **Restart to update**. See [Updates](updates.md). |

### Appearance

| Setting | What it does |
| ------- | ------------ |
| Theme | Light, Dark or System (the default). |
| Use 24-hour time | Shows 14:00 instead of 2:00 PM. |
| App icon | Default, Amber or Silver icon in the Dock. |
| Notes list | Shows each note's folder (on at first) and tags (off at first) in the sidebar. |
