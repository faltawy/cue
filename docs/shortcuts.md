# Keyboard shortcuts

This page lists every keyboard shortcut in Cue. You can change the coach and dictation shortcuts in Settings.

## In any app

| Keys | What it does |
| ---- | ------------ |
| ⇧⌘K | Shows or hides the coach. Change it in **Settings → General → Coach shortcut**. |
| ⌃⌥Space | Dictation: hold, speak, let go. Works only when dictation is on. Change it in **Settings → Dictation**. |
| Esc | Cancels a dictation |

## In Cue

| Keys | What it does |
| ---- | ------------ |
| ⌘N | New note |
| ⇧⌘N | New note that starts recording. If you're already recording, it opens that note. |
| ⌘K | Search notes, people, actions and settings |
| ⌘, | Opens Settings |
| ⌘\ | Shows or hides the sidebar |
| ⌘= / ⌘- / ⌘0 | Makes everything bigger, smaller, or normal size |
| Esc | Leaves Settings, Calendar, Contacts, Folders, Templates or Automations, and closes a note window |
| ⌘Q | Quits Cue. If you're recording, Cue asks first. |

### Note list

| Keys | What it does |
| ---- | ------------ |
| ⌘-click or ⇧-click | Selects several notes |
| ⌘A | Selects all notes |
| Delete | Deletes the selected notes (Cue asks first) |
| Double-click | Opens a note in its own window |

### Inside a note

| Keys | What it does |
| ---- | ------------ |
| ⌥⌘← / ⌥⌘→ | Goes to the previous or next tab (Summary, Memos, Transcript) |
| ⌘F | Finds text in the open tab |
| Return / ⇧Return | Goes to the next or previous match |
| / | Opens the insert menu |
| @ | Mentions a note, person, organization or folder |
| ⌘B / ⌘I / ⌘U / ⌘` | Bold, italic, underline, code |
| ⌘Z / ⇧⌘Z | Undo, redo |
| Space | Plays or pauses the recording (Transcript tab, when you aren't editing) |
| ⌘S or Esc | Finishes editing the transcript |

### Search (⌘K)

| Keys | What it does |
| ---- | ------------ |
| ↑ ↓ | Moves through the results |
| Return | Opens or runs the selected result |
| Esc | Closes search |

### Templates

| Keys | What it does |
| ---- | ------------ |
| ⌥↑ / ⌥↓ | Goes to the previous or next template |

## In the coach panel

| Keys | What it does |
| ---- | ------------ |
| ⌘K | Opens the actions menu |
| ⌘J | Catch me up (while recording) |
| ⇧⌘O | Starts a new chat |
| ⇧⌘C | Copies the last answer |
| / | Goes to the question box |
| Return / ⇧Return | Sends, or starts a new line |
| ↑ | Brings back your last question (when the box is empty) |
| Esc or ⌘. | Stops the answer, or skips the coach's question |
